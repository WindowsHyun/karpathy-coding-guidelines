Private-repository-ready ChatGPT Skill adapted from `multica-ai/andrej-karpathy-skills`.

## What is included

- `skill.zip` — validated ChatGPT Skill package for upload to the ChatGPT Skills library.
- `skills/karpathy-coding-guidelines/` — editable source of the ChatGPT-compatible skill.
- `skills/karpathy-coding-guidelines/references/upstream.md` — upstream provenance and adaptation notes.

## Install in ChatGPT

Open the ChatGPT Skills library (`/skills`) and upload `skill.zip`. Once installed, ChatGPT can apply it across supported chats/projects based on the skill description.

## GitHub privacy note

The upstream repository is public. GitHub ties a fork's visibility to its upstream repository network, so a true fork of a public repository remains public. To keep this adaptation private, create a new private repository and upload/push this directory as a standalone repository rather than using the Fork button.
